# Databricks Emissions Lab

My hands-on learning journey with Databricks and Data Engineering.

## About This Project

This project documents my beginner-level exploration of US emissions data using the Databricks Lakehouse platform.

I am building this project incrementally as I learn data exploration, data cleaning, ETL workflows, and data pipeline development.
